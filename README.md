# Donald-Trump-Tweets-VS-Bitcoin

Exploring the relationship between Donald Trump's tweets and Bitcoin price movements using Python and basic machine learning techniques.

## Project Overview
This project investigates whether public statements from Donald Trump on Twitter are associated with changes in Bitcoin price behavior.

The analysis includes:
- Data collection and preprocessing
- Exploratory data analysis
- Visualization of Bitcoin price movements around tweet events
- Investigation of potential correlations between tweets and market behavior

## Tools Used
Python, Pandas, NumPy, Matplotlib, TimeSeriesSplit, GridSearchCV, XGBoost
